# DP-1 – Osnove AWS-a i okruženje
## Medallion Architecture
The Bronze layer stores raw data from different sources.
The Silver layer cleans and validates the data.
The Gold layer contains prepared data for business analysis.
## Data Roles
A Data Engineer builds and maintains data pipelines.
A Data Analyst analyzes data and creates reports.
A Data Scientist uses data to build models and make predictions.
